# node-js-crud-api

### Running the Application Locally

Use the following commands to install and run the application:

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the application in development mode:**
   ```bash
   npm run start:dev
   ```
3. **Start the application in production mode:**
   ```bash
   npm run start:prod
   ```
4. **Run the application with a load balancer in development mode:**
   ```bash
   npm run dev:multi
   ```
5. **Run the application with a load balancer in production mode:**
   ```bash
   npm run start:multi
   ```
